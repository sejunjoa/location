당면과제

1. user 페이지의 기간 설정 버튼 내부의 텍스트를 admin 페이지 기간 설정 버튼 텍스트와 완벽히 동일하게 대체

2. admin 페이지의 기간 설정 버튼의 위치가 조정되지 않았는데, 그냥 기간 설정 버튼을 이름 검색창과 동일한 폭과 높이로 이름 검색창 아래에 배치, 그리고 그 아래에 1:1:1의 폭으로 구역, 중대, 상태 필터를 배치 (제시한 사진 참고)

3. 생활관에서 최초로 출발하는 로그 카드에 출발 시간과 더불어 도착 예정 시간까지 표시

4. user 페이지의 '[부대명] 위치 현황' 텍스트 아래에, '복귀까지' 라는 텍스트를 추가. 복귀까지 텍스트 우측에 '복귀 예정 시간-현재시간' 을 나타내는 타이머를 표시, 초과되면 '초과됨' 아이콘 추가

5. admin 페이지 구역 추가 버튼 내부의 텍스트를 상세현황 탭의 것으로 통일

6. 모든 페이지의 기간 설정 버튼의 텍스트와 배경색을 나머지 필터 버튼들의 것으로 변경
